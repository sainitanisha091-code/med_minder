# 💊 MedMinder

**MedMinder** is a responsive medicine reminder and management web application built using **HTML, CSS, and Vanilla JavaScript**. It helps users manage their medicines, set reminders, track medicine history, and monitor medicine stock through a simple and user-friendly interface.

## 🚀 Features

* 🔐 **Login & Logout**

  * User authentication
  * Session management
  * Protected application pages

* 👤 **Multiple User Types**

  * Personal User
  * Hospital/Admin User

* 💊 **Medicine Management**

  * Add medicines
  * Set medicine reminders
  * Track medicine details
  * Manage medicine stock

* 📦 **Medicine Stock Tracking**

  * Track available medicine quantities
  * Display stock information on dashboard cards

* 🔔 **Reminder Notifications**

  * Medicine reminder functionality
  * Browser notifications
  * Service Worker support

* 📊 **Dashboard**

  * Medicine overview
  * Reminder information
  * Stock status
  * Pie chart visualization

* 📜 **Medicine History**

  * Maintain medicine-related history
  * View previously stored information

* 💾 **Local Data Storage**

  * Local Storage for persistent data
  * Session Storage for login sessions
  * JSON-based data handling

* 📱 **Responsive Design**

  * Mobile-friendly interface
  * Responsive layouts
  * Simple and intuitive navigation

## 🎯 Objective

The objective of MedMinder is to provide a simple digital solution for managing medicines and reminders while applying practical frontend development concepts.

The project was also developed to gain hands-on experience with **JavaScript, DOM manipulation, browser storage, event handling, notifications, responsive design, and user authentication**.
